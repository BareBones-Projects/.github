## Exceptions and review gates

1. `.github-private` is empty and cannot support a normal review branch or PR; initialize only with explicit approval.
2. SVG previews render in READMEs. GitHub repository social-preview **settings** require separately uploading supported raster artwork; this is not configured by a source-file commit.
3. Existing application source files, third-party licenses, binaries, JSON fixtures, and generated files were **not** mass-rewritten to insert attribution. Preserve valid syntax and licensing, add language-appropriate headers only after review.
4. CI checks distinguish documentation integrity from functional tests and from verified security. Do not merge a failing PR.
5. For ALT projects, signed notice blocks remain at canonical source positions; avoid moving them outside the first/last regions.
6. BareTools candidate registry in [BareTools PR #1](https://github.com/BareBones-Projects/BareTools/pull/1) is proposed, **not approved for consolidation**.
7. Obsidian sample plugin dependency review is blocked by GitHub Dependency graph configuration; Obsidian Workflows has Markdown formatting/lint issues to resolve.

Review all diffs, run project-specific checks, confirm permissions and security settings, verify preview accessibility, then merge approved PRs. No production release is implied by passing docs CI.
