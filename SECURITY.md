# Security Policy

## Reporting
Use the repository's private GitHub vulnerability reporting feature if available. Otherwise contact the maintainers privately using their published contact information. Do not post exploits, private data or secrets in public issues.

## Scope
Alpha/prototype status does not imply production security. Protect secrets, use least-privilege credentials, review dependencies, and require pull-request review and project-specific checks. No response or resolution timeline is guaranteed.
